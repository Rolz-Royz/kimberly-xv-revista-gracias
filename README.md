# Kimberly · The Thank-You Issue

Magazine-style thank-you page for the guests of Kimberly's XV (August 29, 2026).
Built by REGO Agency. Same photos, videos and music as
[kimberly-xv-gracias](https://github.com/Rolz-Royz/kimberly-xv-gracias); same editorial
design as the invitation experiment (kimberly-xv-invitation), rewritten as a post-party recap.

- Magazine cover gate that turns like a page
- Cover-story video, Kimberly's thank-you letter, clickable contents
- The night by the numbers, the day recapped with a sticky clock, the traditions,
  zooming photoshoot grid, "after dark" party pages with a camera flash,
  society pages, thank-you to the padrinos, photobooth backstage, back cover
- English / Spanish toggle, background music (Zoé — "Luna" excerpt), photo viewer

Not indexed by search engines (see `robots.txt` and the `noindex` meta tag).

## Local preview

    node server.js     # http://localhost:4630

Add `?open` to the URL to skip the cover animation.
